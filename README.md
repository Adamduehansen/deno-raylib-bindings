# Dungeon Heroes

## GDD (WIP)

- Gameplay is separated into multiple rooms.
- Monsters will spawn each time new room is discovered.
- The game is turn-based switching the player and the monsters.
- A monster will spawn at the end of the players turn.
- The player needs to kill x amount of monster to finish the game.
- The player can choose from 2 classes: wizard or knight.
